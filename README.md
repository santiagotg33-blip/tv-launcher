# tv-launcher

Lanzador (pantalla de inicio) para Hyundai Android TV 7.1.1.
Dock: Magma, Kodi, YouTube, Aptoide TV. Debajo van las demas apps.

Para cambiar el dock, edita la lista `DOCK` en
`app/src/main/java/com/tvlauncher/app/MainActivity.java`.

El APK se compila solo en GitHub Actions y queda en Releases.
